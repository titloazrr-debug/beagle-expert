# Images Beagle

Placez ici vos fichiers JPG (remplacent les placeholders) :

| Fichier | Usage |
|---------|--------|
| `hero.jpg` | Page d’accueil (hero) |
| `sante.jpg` | Fiche Santé + cartes |
| `alimentation.jpg` | Fiche Alimentation + cartes |
| `education.jpg` | Fiche Éducation & comportement + cartes |
| `soins.jpg` | Fiche Soins & entretien + cartes |
| `budget.jpg` | Fiche Budget & équipement + cartes |
| `histoire.jpg` | Fiche Histoire & standard + cartes |
| `og-default.jpg` | Open Graph / Twitter par défaut (idéalement **1200×630**) |

Chemins publics stables : `/images/beagle/<fichier>`.

Le code d’intégration est dans `src/lib/beagle-images.ts` et `src/components/BeagleImage.tsx`.
